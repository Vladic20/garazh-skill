# After Effects animations

The engine plays **Lottie**, the JSON format After Effects exports through the Bodymovin / LottieFiles plugins. An animation made in AE (shape layers, masks, trim paths, precomps, most expressions) renders inside the video frame by frame: it is seeked to the exact frame for each time `t`, so it is deterministic and sharp at any resolution. After Effects itself is **not needed at render time**.

## Use one in a story

```json
{ "type": "lottie", "src": "pack:check", "x": 640, "y": 300, "w": 300, "h": 300, "delay": 0.5 }
{ "type": "lottie", "src": "anim/logo.json", "x": 640, "y": 240, "w": 900, "h": 140, "loop": true }
```

| option | default | meaning |
|---|---|---|
| `src` | — | `pack:<name>` (starter pack below) or a path relative to the episode folder (`anim/logo.json`) |
| `w`, `h` | the animation's own size | box in world px; the aspect ratio is kept |
| `loop` | `false` | `false` = play once and hold the last frame; `true` = repeat |
| `speed` | `1` | playback speed |
| `from`, `to` | whole animation | play only a frame range (AE frame numbers) |

Plus every prop option: `x`, `y`, `scale`, `rot`, `z`, `enter`, cues (`on` / `at` / `delay`), `out`, `then`. Playback starts when the prop appears (its `t0`). A lottie prop gets no cartoon outline, and it is pixelated in the `pixel` look like everything else.

**Starter pack** (`template/lottie/`, generated by `lib/lottie-pack.mjs`, MIT): `check` (tick in a circle), `burst` (rays + ring, loopable), `loader` (spinner), `heart` (beat), `arrow` (draws itself), `sparkle` (twinkling stars), `pin` (map pin drop), `confetti`.

## Bring your own

- **From After Effects**: install the free *Bodymovin* or *LottieFiles for After Effects* plugin, export the comp as JSON (shape layers work best; convert text to shapes or glyphs; avoid layer effects lottie-web does not support, such as most third-party plugins). Put the `.json` in the episode folder. If it uses images, export them embedded (base64) so the JSON is self-contained.
- **From LottieFiles**: download the Lottie JSON of a free animation (check its licence; the "Lottie Simple License" allows commercial use).
- **Check**: `node make.mjs <slug> --stills auto` shows whether it renders; a missing file fails the build with the list of pack names.

## Driving After Effects directly (when it is installed)

With After Effects installed (it comes with Creative Cloud plans that include it), two more things become possible:
1. **Render AE templates** with `aerender` (ships with AE): fill text / swap footage through an ExtendScript (`.jsx`) and render the comp to a PNG sequence or ProRes 4444 with alpha, then place it in a scene. Open-source helper: [nexrender](https://github.com/inlife/nexrender).
2. **Let Claude build comps in AE** through an After Effects MCP server (an extension panel inside AE that runs ExtendScript for Claude), e.g. [dakkshin/after-effects-mcp](https://github.com/dakkshin/after-effects-mcp) or [junkdoge-joe/after-effects-mcp](https://github.com/junkdoge-joe/after-effects-mcp). Animations built this way are exported back as Lottie for the engine.

`bash scripts/bootstrap.sh` reports whether `aerender` was found.
